## 二、候选功能详细档案

### CAND-01：思源文档划选块右键一键生成填空卡片（快捷划词制卡）
- **是什么**：
  在思源笔记正文编辑器内，当用户选中包含高亮语法（如 `==重要概念==`）的一段文字或一个列表块时，在弹出的块图标或上下文菜单中增加一项「一键生成填空题/闪卡」，直接静默提取挖空并写入当前激活题库的「/学习闪卡」文档，并在右下角弹出成功提示。
- **解决什么问题**：
  目前用户阅读笔记若想制题，需右键「将此块转为小驴考试试题」打开录题工坊，再确认保存，链路为 4 步。该功能可将阅读过程中的零摩擦制题压缩至 1 步，实现“读到哪、卡制到哪”。
- **影响哪类用户**：
  重度依赖思源笔记做文献研读、考研专业课整理与法条背诵的学习者。
- **预估成本**：
  **低**。已具备 `cloze.ts` 解析器与 `app.writeManualQuestion` 底层通道，只需在 `src/index.ts:onBlockIconClick` 补充一个菜单触发回调。
- **与现有功能是否重叠**：
  不重叠。与录题工坊的「划重点挖空子面板」是互补关系（工坊侧重批量整理，菜单侧重单块快速摘录）。

### CAND-02：模考交卷后错题自动打标一键加入“模考靶向集”
- **是什么**：
  全真模考交卷并查看考场报告后，在报告页面新增「🎯 生成本场专属攻坚卷」按钮。自动为该场次所有做错的试题打上 `mock-run-{timestamp}` 专场标签，并在错题本中支持一键筛选或一键生成二刷微模考。
- **解决什么问题**：
  目前模考错题会自动流入全量错题本，但与日常练习错题混合在一起。考生往往在大考后第二天想专门把“昨天模考错的 15 道题”再做一遍，目前需要手动翻找或靠记忆比对。
- **影响哪类用户**：
  临考 1~2 个月、每周固定进行 1~2 次全真限时模考的深度备考考生。
- **预估成本**：
  **中**。需在 `MockTab.svelte` 结算卡片和 `ReportTab.svelte` 补齐打标动作与快速特训跳转通道。
- **与现有功能是否重叠**：
  无重叠。底层基于现有的 `userTags` 属性与特训调度体系，不产生多余状态。

### CAND-03：录题工坊公式输入实时 LaTeX 语法高亮与快速纠错
- **是什么**：
  在 `ManualStudioView.svelte` 的题干与选项输入框中，当检测到 `$ ... $` 或 `\frac` 等数学符号时，对成对括号（`{}`、`[]`）进行实时闭合校验；若出现未闭合的大括号或缺失下标，在输入框下方以柔和黄色角标提示“检测到公式大括号未闭合”，避免提交后渲染报错。
- **解决什么问题**：
  考生在录入复杂数学微积分、物理力学公式或化学方程式时，常因漏写一个 `}` 导致做题时出现 MathJax 红字报错，造成做题时困扰。
- **影响哪类用户**：
  高中/大学数理化、考研数学、工程技术类刷题考生。
- **预估成本**：
  **中**。可在前端用轻量纯函数（括号栈检查）实现，无需引入体积庞大的重量级代码编辑器组件。
- **与现有功能是否重叠**：
  无重叠。现有的「清洗公式」按钮仅处理空格，无实时语法纠错能力。

### CAND-04：思源日记/主页内嵌小驴考试“每日研学微测”交互挂件 (Widget)
- **是什么**：
  开发一个思源挂件块（Widget）组件，用户可以将其嵌入到自己的日记模板或个人主页中。挂件内部卡片优雅展示“今日计划剩余 N 题”、“连胜天数”、“待急救核心考点”，并内嵌一个“开始练习”快捷按钮，点击直接在右侧分屏唤起小驴练习台。
- **解决什么问题**：
  打破插件界面与思源日常工作流的物理隔阂，让备考进度自然融入用户的晨间日记与日常知识库仪表盘。
- **影响哪类用户**：
  深度使用思源笔记日记、看板与个人知识管理（PKM）的高粘性用户。
- **预估成本**：
  **较高**。需单独打包一个静态 iframe/widget 模板，并通过思源 API 与小驴考试 EventBus 建立跨窗口 postMessage 通信。
- **与现有功能是否重叠**：
  无重叠。是对现有 Tab 主界面的场景化外延。

### CAND-05：做题心流模式下背景白噪音音量平滑淡入淡出（Audio Cross-fade）
- **是什么**：
  在 `PracticeSessionView.svelte` 点击耳机图标开启/关闭自然细雨声心流白噪音时，声音音量在 800ms 内平滑从 0 渐变到 0.05（淡入），或从 0.05 渐变到 0 后暂停（淡出）。
- **解决什么问题**：
  消除突然开启/关闭声音时给耳膜带来的突兀感，提升深度沉浸专注时的听觉质感。
- **影响哪类用户**：
  习惯戴降噪耳机刷题的考生。
- **预估成本**：
  **低**。纯 Web Audio API（`gainNode.gain.linearRampToValueAtTime`），无需第三方库。
- **与现有功能是否重叠**：
  纯交互质感增强，无功能重叠。

### CAND-06：简答题主观自评采分点支持分步“一键折叠已满分项”
- **是什么**：
  在简答题自评采分点面板顶部增加「仅看扣分项」切换药丸，点击后自动收起所有评为“优秀/完全符合”的满分采分点，仅突出显示“部分符合”或“未提及”的项。
- **解决什么问题**：
  在申论、法考等包含 6~10 个采分点的大题中，减少考生在完成自评后的视觉认知负荷，一眼看清失分短板。
- **影响哪类用户**：
  文科、法学、医考等主观题考生。
- **预估成本**：
  **低**。Svelte 5 `$derived` 过滤状态。
- **与现有功能是否重叠**：
  无重叠。现有的采分点面板仅能平铺展示全部细项。

### CAND-07：错题本支持“艾宾浩斯记忆周期视图”（按 1/2/4/7/15 天自动时间桶聚合）
- **是什么**：
  在错题本（WrongbookStudioView）分栏中增加一个“遗忘拐点看板”，将未消灭的在册错题按最近做错距今时间自动聚合为「今天需复习 (1d)」、「3天临界点」、「7天深层巩固」、「15天固化」四列看板，支持按看板列一键发起强化特训。
- **解决什么问题**：
  目前错题本列表为平铺式，当错题累积到 50 题以上时，考生往往不知道今天应该先重练哪几题，容易产生“不知道从哪下手”的焦虑。
- **影响哪类用户**：
  高强度备考、重视艾宾浩斯遗忘曲线规划的考生。
- **预估成本**：
  **中**。纯前端根据 `w.lastWrongAt` 计算时间差分组，复用既有特训组卷通道。
- **与现有功能是否重叠**：
  无重叠。是对在册错题维度的全新时序切片展现。

### CAND-08：题库浏览抽屉题目变更版本历史差异高亮对比（Diff View）
- **是什么**：
  在试题详情预览抽屉（QuestionPeekDrawer）的历史修改记录（Revisions）中，点击某条历史版本不仅展示旧版内容，还能将新旧题干/选项的增删文字以红/绿色块高亮呈现（类似 Git diff）。
- **解决什么问题**：
  帮助题库审校人员或考生一眼看清本次修改具体修了哪一个错别字、更改了哪个选项或微调了哪句解析，避免反复肉眼找不同。
- **影响哪类用户**：
  题库录入者、审题老师、精细化考点维护用户。
- **预估成本**：
  **低**。前端纯文本字符级轻量对比。
- **与现有功能是否重叠**：
  无重叠。现有的历史版本仅能查看纯文本，无对比高亮。

### CAND-09：模考成绩卡片一键插入思源当前日记文档（备考进度归档）
- **是什么**：
  在模考报告页面，除“复制 Markdown”外，增加一个「插入当前每日笔记」按钮。点击后自动通过思源 API 查询今天打开的日记文档，在文末以引用块追加本次全真模考的得分率、耗时与及格判定。
- **解决什么问题**：
  简化考生考后手动切换页签并粘贴的过程，实现一键归档。
- **影响哪类用户**：
  习惯写备战日记的考生。
- **预估成本**：
  **低**。复用已有的 `app.appendBlock` 与日记路径解析服务。
- **与现有功能是否重叠**：
  无重叠。现有功能仅支持复制到剪贴板或导出为独立新文档。

### CAND-10：模考答题卡支持大类手风琴折叠（按单选/多选/判断分卷跳题）
- **是什么**：
  在考场右侧答题卡中，当题目总数超过 40 题时，自动按模块（Section）生成可折叠的分区手风琴（例如“一、基础单选 1-20”、“二、专业多选 21-35”），点击标题可折叠或展开对应区域。
- **解决什么问题**：
  减少考场长卷面时的纵向翻动距离，方便考生集中检查某一大题的答题完成度。
- **影响哪类用户**：
  医考、法考、考公等 100+ 题量大试卷考生。
- **预估成本**：
  **中**。需配合答题卡紧凑网格做折叠容器渲染。
- **与现有功能是否重叠**：
  无重叠。现有的答题卡仅能按“全部/未答/标记”过滤，不能按大题模块折叠。

### CAND-11：学情概览支持日/周/月作答热力柱线图自由切换
- **是什么**：
  在学情报告的“作答趋势”卡片上方，增加一个分段切换器「日 / 周 / 月」，支持将作答量和正确率按周平均、月汇总呈现平滑宏观折线。

  对于半年或一年期长备考考生，近 30 天视图颗粒度过细，无法一眼看清各月份的备战起伏大趋势。
- **影响哪类用户**：
  长备战周期的考研、法考、CPA 用户。
- **预估成本**：
  **低**。前端纯数据时序切片聚合。
- **与现有功能是否重叠**：
  纯视图维度扩展，无重叠。

### CAND-13：全局命令面板（⌘K）支持拼音首字母模糊检索
- **是什么**：
  在 ⌘K 命令面板中，除中文匹配外，支持输入命令名称的拼音首字母缩写进行匹配（例如输入 `ctb` 匹配“错题本”、输入 `dtk` 匹配“答题卡”、输入 `zdbk` 匹配“今日备考”）。
- **解决什么问题**：
  免去中文输入法在英文状态与选词之间的频繁切换，实现全键盘极速盲打跳转。
- **影响哪类用户**：
  追求极速操作的键盘流效率考生。
- **预估成本**：
  **低**。前端为静态命令列表缓存拼音首字母映射。
- **与现有功能是否重叠**：
  纯检索体验增强，无功能重叠。
