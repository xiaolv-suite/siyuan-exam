# 🐴 小驴考试 × 小驴闪卡：公共集市互通设计规范与对接指南

> **目标**：实现《小驴考试》（`siyuan-exam`）与《小驴闪卡》（`siyuan-lv-cards`）在公共知识集市、闪卡包、试卷模型上的**100% 协议级互通**与**考背一体闭环**。

---

## 一、 核心架构：去中心化公共知识集市协议

两个插件采用完全相同的轻量集市目录协议（`MarketplaceCatalog` 与 `MarketplaceItem`）：

```typescript
export interface MarketplaceItem {
  id: string; // 唯一英文 slug，如 "math-highschool-theorems"
  title: string; // 题库/卡包名称
  subtitle?: string; // 一句话亮点
  description: string; // 考点范围与介绍
  kind: "exam_bank" | "flashcard_deck" | "both"; // 题卡两用
  category: "all" | "math" | "science" | "language" | "qualification" | "computer" | "humanities" | "general";
  tags: string[]; // 检索标签
  author: { name: string; url?: string };
  version: string; // 语义化版本号，如 "1.2.0"
  itemCount: number; // 题目/卡片数量
  license: "CC0" | "CC-BY-4.0" | "CC-BY-NC-4.0" | "Public Domain" | "MIT";
  downloadUrl: string; // 下载直链（JSON / 内嵌 embedded:...）
  previewItems?: Array<{ stem: string; answer?: string; options?: string[]; analysis?: string }>;
  embeddedQuestions?: Question[]; // 官方精选零版权内嵌题目
}
```

## 三、 集市核心能力演进（全量功能矩阵）

1. **🏛️ 顶层一级常驻导航**：与录题工坊平级，宽幅响应式卡片画廊与全域统计 Hero Bar。
2. **🛒 跨学科试题/闪卡篮 (Cart & Selective Stash)**：
   - 预览时任意勾选题卡放入试题篮；
   - 悬浮胶囊一键操作：
     - `🚀 就地启动练习`：秒级开练，零等待；
     - `🗂️ 导出跨学科闪卡包`：直接打包 `.lvcards`；
     - `📥 存为专属新题库`：自动写入思源笔记本。
3. **📊 品质画像与难度梯度看板 (Quality Metrics Dashboard)**：
   - 题型构成占比（单选/多选/判断）；
   - ★1-5 难度梯队三色阶梯条（基础/进阶/拔高）；
   - 秒杀要诀覆盖率看板。
4. **🌳 考点大纲全景树与三模切换 (Taxonomy Tree)**：
   - 试看支持「📝 题库试卷 / 🗂️ 小驴闪卡 / 🌳 考点大纲」三模切换；
   - 考点树支持按章节一键全选入篮。
5. **⬆️ 增量差量更新与无损合并 (Delta Sync & Patch Merge)**：
   - 自动比对本地已安装题库与集市远端新版本；
   - 发现新题与修订时，一键无损打补丁，**绝对保留用户历史作答、错题本状态与 FSRS 记忆参数**。
6. **📦 题库发布向导与隐私脱敏自检 (Marketplace Packaging & Sanitizer)**：
   - 一键将本地自制题库打包为集市源；
   - 自动扫描 Windows/Unix 本地绝对磁盘路径与 `siyuan://blocks/...` 私有块引用，保障分享合规。

## 四、 小驴闪卡端接入指导建议

小驴闪卡（`siyuan-lv-cards`）只需将以下核心纯函数模块直接放入其代码库即可复用同一架构：
1. `src/core/lvcardsBridge.ts`（通用闪卡协议适配器）
2. `src/core/marketplace.ts`（公版 8 大学科集市目录与第三方订阅源解析器）
3. `src/core/marketplaceCart.ts`（闪卡篮模型与卡包品质画像）
4. `src/core/marketplaceSync.ts`（牌组差量检测与无损合并、发布向导）
