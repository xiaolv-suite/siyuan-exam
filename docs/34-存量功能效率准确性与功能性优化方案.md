# 小驴考试（siyuan-exam）存量功能效率、准确性与功能性优化方案

> **优化主旨**：坚决不增加脱离主线的新旁支功能，在现有【出题】与【做题】两大核心架构上，从**效率（Efficiency）**、**准确性（Accuracy）**、**功能性（Functionality）**三大维度纵深提升体验与工程品质。  
> **基线分支**：`refocus/core-loop` (v0.14.0)

## 二、关键技术落地细则

### 1. 【出题准确性】答案归一化容错升级 (`src/core/answer.ts`)
```typescript
export function normalizeAnswer(type: Question["type"], raw: string): string | null {
  const s = foldText(String(raw ?? ""));
  if (!s) return null;
  if (type === "judge") return normalizeJudge(s);
  if (type === "single") {
    // 兼容 "A", " (B) ", "【答案】C", "D.", "答案:A"
    const m = s.toUpperCase().match(/(?:答案\s*[:：]\s*)?[（(\[【]?\s*([A-J])\s*[)）\]】.]?/i);
    return m ? m[1].toUpperCase() : null;
  }
  if (type === "multiple") {
    // 兼容 "A,B,C", "A、B、D", "【答案】ABCD"
    const letters = s
      .toUpperCase()
      .replace(/[^A-J]/g, "")
      .split("");
    const uniq = [...new Set(letters)].sort();
    return uniq.length ? uniq.join("") : null;
  }
  return s;
}
```

### 2. 【出题效率】录题工坊快捷键连打与自动聚焦 (`ManualStudioView.svelte`)
- 绑定全局/输入框快捷键：
  ```svelte
  <svelte:window onkeydown={(e) => {
    if ((e.ctrlKey || e.metaKey) && e.key === "Enter") {
      e.preventDefault();
      void onsaveManual();
    }
  }} />
  ```
- 保存成功后触发 `onblankManualDraft()`，并自动调用 `document.getElementById("lv-manual-stem")?.focus()`。

### 3. 【做题效率】数字键 `1-4` 对应 `A-D` 选项直选
- 在键盘处理服务中，当处于单选或多选题且当前未聚焦输入框时，允许按下数字键 `1`（选择 A）、`2`（选择 B）、`3`（选择 C）、`4`（选择 D）。

### 4. 【做题功能性】模考成绩单逐题过滤
- 在成绩单的错题清单面板增加：
  - `全部题目 ({score.total}题)`
  - `仅看错题 ({wrongList.length}题)`
  - `存疑蒙猜 ({flaggedCount}题)`
- 帮助考生在 100+ 题量大卷中集中逐题复核。

## 三、验证与测试规划
1. **纯函数单元测试**：针对 `normalizeAnswer` 扩展至少 10 项极端边界单测（含带前缀、带各类括号、混杂汉字等）。
2. **多空判分容错测试**：针对 `gradeWithSpec` 扩展中英文标点混杂多空测试。
3. **宿主真机回归**：执行 `node scripts/e2e-isolated.mjs`，确保 15/15 真实思源内核流程 100% 通过。
