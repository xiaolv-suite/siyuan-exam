# 小驴考试（siyuan-exam）内测说明、发版节奏与反馈模板

## 1. 发版与冻结纪律

1. **核心功能冻结**：在完成首轮 3–5 名真实用户连续使用两周前，冻结一切偏离「导入/录题 → 今日练习 → 错题攻坚 → 全真模考 → 复盘证据」核心闭环的新特性（CAT/IRT、考纲换版比对、认知画像、口语测评、教师工作台等一律不排期）。
2. **每周最多发版一次**：不再每次提交或每批改动就打标签发版；日常修复合入 `Unreleased`，按周（或出现阻断级数据/启动缺陷时）集中打包发布一次 Beta。
3. **优先级由真实反馈决定**：两周内测结束后，只按真实用户卡住的步骤重新排序 [docs/TODO-POOL.md](TODO-POOL.md)，不再启动无用户证据的检查表式自转优化。
